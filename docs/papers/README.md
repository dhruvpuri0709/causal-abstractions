# Papers

Works cited in `../proposal.tex`, by BibTeX key. PDFs are not included in this repository; use the links below.

| Key | Paper | Source | Role in the project |
|---|---|---|---|
| `geiger2021causal` | Causal Abstractions of Neural Networks (NeurIPS 2021) | [arXiv:2106.02997](https://arxiv.org/abs/2106.02997) | Interchange interventions and IIA |
| `geiger2024finding` | Finding Alignments Between Interpretable Causal Variables and Distributed Neural Representations (CLeaR 2024) | [arXiv:2303.02536](https://arxiv.org/abs/2303.02536) | DAS; hierarchical equality; Table 1 (training-set IIA, best of 3 seeds) and §4.4 (random networks) are the results to reproduce |

| `sutter2025nonlinear` | The Non-Linear Representation Dilemma (NeurIPS 2025) | [arXiv:2507.08802](https://arxiv.org/abs/2507.08802) | DAS reimplementation for MLPs; hidden-size sweeps; alternative algorithms (code in `external/`) |
| `hewitt2019control` | Designing and Interpreting Probes with Control Tasks (EMNLP 2019) | [arXiv:1909.03368](https://arxiv.org/abs/1909.03368) | Control tasks as a null for probes |
| `shi2024hypothesis` | Hypothesis Testing the Circuit Hypothesis in LLMs (NeurIPS 2024) | [arXiv:2410.13032](https://arxiv.org/abs/2410.13032) | Circuit claims framed as hypothesis tests |
| `cameron2008bootstrap` | Bootstrap-Based Improvements for Inference with Clustered Errors | [NBER TWP 344](https://www.nber.org/papers/t0344) (working-paper version of the 2008 REStat article) | Cluster bootstrap |
| `westfall1993resampling` | Resampling-Based Multiple Testing (Wiley, 1993) | Book, no PDF included | Max-statistic null for selection correction |
